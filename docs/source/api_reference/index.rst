Overview
--------

StatQA provides a comprehensive API for statistical analysis and Q/A generation:

- **Metadata**: Parse and enrich variable metadata from various sources
- **Analysis**: Univariate, bivariate, temporal, and causal statistical analysis
- **Q/A Generation**: Create question/answer pairs with provenance tracking
- **Visualization**: Generate publication-quality statistical plots
- **Utils**: Helper functions for statistics, I/O, and logging
- **Types**: TypedDict definitions for structured data
- **CLI**: Command-line interface for batch processing
